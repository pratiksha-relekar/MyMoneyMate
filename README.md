# 💸 MyMoneyMate – Personal Finance Tracker App

MyMoneyMate is a beautifully designed Flutter-based personal finance app that helps users manage their daily income, expenses, and savings in one place. Built using Flutter and Firebase, the app offers a clean UI and intuitive experience for anyone looking to track their financial habits.

---

## 🔥 Key Features

- 🔐 Firebase Authentication (Login/Signup)
- 📊 Dashboard with total balance, income & expenses
- ➕ Add and manage transactions easily
- 🗑️ Edit or delete entries
- 📅 Monthly & yearly tracking
- 📱 Clean and modern UI with custom branding

---

## 🧪 Tech Stack

- Flutter (Frontend)
- Dart (Programming Language)
- Firebase (Authentication + Firestore Database)

---

## 📥 How to Download & Run

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-username/mymoneymate.git
   cd mymoneymate
````

2. **Install Dependencies**

   ```bash
   flutter pub get
   ```

3. **Connect Firebase**

   * Setup your Firebase project
   * Add your `google-services.json` in `android/app/`

4. **Run the App**

   ```bash
   flutter run
   ```

> 📱 The app supports Android. iOS support will be added soon.
